CSS Specificity & Cascade

CSS Specificity:- Selector Same ek hi Tarah Ka Hai. Class Selector, Id Selector, Jo Bad Mei Lagaya Gya Hoga Vo He Execute Hoga.

Universal Selector Specificity is 1.

Class & Id Selector Specificity is 10.

Attribute Selector Specificity is 10.

Complex Selector ( h2.blue ) Specificity is 1 + 10.

Inline Style Selector ( style="" ) Specificity is 1000.

Answer:- 1 + 10 + 10 + 10 + 10 = 41. (:hover is the Pseudo class Selector Specificity is 10)
