Box-Sizing:Border Box means jo mere element content ki height hai 200px, Border or Padding 3ino ko include krke likhi hai. Content (Height) + Border + Padding.

Margin Collapse: Agar 2 elements ki margin overlap ho rhi hai jo bhi maximum margin hai vo bs ek bar lagegi. For ex:- Maine First Box mei margin 25px di hai or Second Box mei margin 25px di hai or dono mei maximum margin 25px hai to 25px lagegi. Agar First Box mei margin 25px hai or Second Box mei margin 35px hai to Maximum margin 35px lagegi.
